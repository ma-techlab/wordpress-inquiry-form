## 5. 不正送信対策

**送信回数の注意（LocalWP）**：LocalWP では、どのブラウザから送っても送信元が同じ（`127.0.0.1` など）として数えられます。そのため、この章の前に行った送信も「10分に5回」に含まれます。5-4 は、最後の送信から**10分以上たってから**始めてください。途中で制限にかかったら10分待ってください。入力エラーになった送信は数えません。

## 9. `<script>` などを含む入力が、画面・メール・CSV で実行されない

`sanitize_text_field()` などがタグを取り除くので、`<script>` は保存されません。そのため、タグを使わずに属性へ入り込もうとする文字列（9-2）でも、出力時のエスケープを確かめます。

### 9-1 タグを含む入力

| 項目 | 内容 |
|---|---|
| 手順 | ログアウトした状態で、下の入力例で送信する。 |
| 入力例 | 種別：問い合わせ<br>会社名：`<script>alert('xss1')</script>（例）スクリプト株式会社`<br>担当者名：`<img src=x onerror=alert('xss2')>試験 三郎`<br>メール：`xss@example.com`<br>内容：`<b>太字</b>` `<script>alert('xss3')</script>本文です。` |
| 期待する結果 | どの画面でも警告ダイアログ（alert）が出ない。<br>一覧と詳細：会社名が `（例）スクリプト株式会社`、担当者名が `試験 三郎`、内容が `太字 本文です。` のように、タグが取り除かれて保存されている。太字にもならない。<br>Mailpit：件名と本文にタグが無く、スクリプトも動かない。<br>CSV（Excel）：タグが無い。 |
| 結果 | ☑ OK ☐ NG |
| メモ | 画面と CSV：自動（`bin/check-localwp.sh`）。タグが取り除かれ、一覧・詳細・CSV にタグと `alert` の文字列が残らない。<br>Mailpit：目で確認。件名 `【問い合わせ】（例）スクリプト株式会社 様より`、本文にタグと `alert` の文字列が無く、内容は `太字 本文です。`。 |
